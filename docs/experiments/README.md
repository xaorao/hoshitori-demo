# Experiments

Small, re-runnable studies made before and during the build. The specifications cite them by number (`E1`, `E2a`, ...) as the evidence for a rule. Each folder holds the script and the results file it wrote. They are research code, not part of the product: they run with the standard library plus the tools their header names, and some need a path to a third-party checkout or tool given in an environment variable (the variable is named where it is read).
