# Hoshitori film

The submission film, "Fixed before the outcome", made with [Remotion](https://www.remotion.dev) (React and TypeScript). The design is in `VIDEO.md`
(the film's own storyboard); this folder is its build. The film is itself a receipt: every number, time, id and line of program output in it
is read from the packed record or from a recording of the product, never typed by hand.

Compositions (30 fps): `Main` 1920x1080, 4200 frames (2:20); `Cut30` 900 frames; `Cut10` 300 frames in 1920x1080 and `Cut10Square` in 1080x1080.

## The four commands

```bash
npm i                # remotion, @remotion/cli, react 19, typescript (exact versions in package.json)
make video           # record, capture, terminals, meta, sound, render, master, cuts, srt, poster
make test            # node:test, no network
make stills FILM_DEV=1   # one still per scene into out/stills/ (dev stand-ins allowed, DEV stamp on every frame)
```

`make video` runs in order: `record` (extract `../docs/record/record.tar.gz` into `public/record/`), `capture` (`../video/capture.py`, Playwright screens
and the keyboard recording into `public/real/`), `terminals` (`../video/record_terminals.sh`, recorded logs with exit codes), `meta` (commit, record
sha256 and render time into `src/build.json`), `sound` (generated with ffmpeg), `render` (the four compositions to `out/`, H.264 High yuv420p CRF 18,
keyframe every 2 s, AAC 192 kbps 48 kHz), `master` (two-pass loudnorm to `LUFS`, default -16, video untouched), `srt` (`main.en.srt`, `main.ja.srt` and
the cuts'), `poster` (scene 0, frame 75).

## Real and drawn

- Real: screens and logs in `public/real/` (listed in `public/real/manifest.json`), the packed record in `public/record/`, the hero receipt named by
  `public/real/hero.json`. A Real screen is only ever cropped or panned, never retouched. Logs are typed from the log's own text; commands are
  shown in a short form (`<cycle>`, `0x0000...dEaD`, `...` for paths) whose every token is the log's.
- Drawn: diagrams and fixed copy (`src/copy.ts`), which carries no measurement.
- `src/data.ts` is the only door for facts. It throws when the manifest is missing, when a scene's asset is not in it, when a log has no exit
  code, or when the commit or record id is missing. `FILM_DEV=1` (make) or `--props='{"dev":true}'` (remotion) allows stand-ins from
  `public/dev/` (`make standins`) and stamps every frame `DEV`; such a render must never be shipped.
- The accent (amber, `#b45309`) means one thing: fixed in time (the seal rule, the seal dot, the two time-stamp marks, the struck forged value,
  the rule under what is not shown).

## Layout

```
src/index.ts, Root.tsx     compositions; calculateMetadata loads the film through data.ts
src/data.ts                record, manifest, logs, hero; refuses missing Real assets
src/select_hero.ts         settled, C3, up-or-down, chance farthest from 50 %, earliest settled, receipt present
src/format.ts              small pure helpers that mirror web/src/format.ts wording
src/logs.ts, rows.ts       recorded terminals: cleaning, exit codes, short command form, terminal plans
src/timing.ts, theme.ts    every frame, size and position; scenes hold no numbers
src/copy.ts                fixed on-screen words
src/captions.en.json, subtitles.ja.json   one entry per beat with its time in and out; `make srt` writes SRT
src/scenes/Scene0..10.tsx  the main cut
src/Cuts.tsx               the 30 s and 10 s cuts
src/ui/                    Crop, Terminal, Captions, SealRule, Seal, IntervalBar ...
src/sound.ts, ui/Sound.tsx tick, tone, buzz, key clicks and the room bed
test/                      node:test
```
